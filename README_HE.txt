LoriLab Manager v11.0

חדש בגרסה זו
1. כפתור "סנכרן לקוחות מ־Drive" במסך לקוחות.
2. קריאת מבנה התיקיות: Lori Lab / עיר / שם לקוח / תאריך.
3. הוספת הערים והלקוחות לרשימה המקומית ללא כפילויות.
4. לאחר הסנכרון הרשימה זמינה גם ללא אינטרנט.
5. שם תעודה בפורמט: סוג (תיאור מספר-זיהוי) זכר/נקבה.
6. הלוכסן / במספר הזיהוי נשמר כפי שהוקלד.

הגדרה חד־פעמית של Google Drive
א. ב-Google Cloud Console צור פרויקט והפעל Google Drive API.
ב. צור OAuth Client ID מסוג Web application.
ג. הוסף ל-Authorized JavaScript origins את כתובת GitHub Pages שלך, לדוגמה:
   https://USERNAME.github.io
ד. במסך לקוחות לחץ "הגדרת Drive".
ה. הדבק את OAuth Client ID.
ו. הדבק קישור לתיקיית Lori Lab הראשית ב-Drive.
ז. שמור ולחץ "סנכרן לקוחות מ־Drive".
