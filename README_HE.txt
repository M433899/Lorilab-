LoriLab Manager v13.1 — תיקון שמירה אוטומטית ל-Google Drive

מה תוקן:
- Drive Sync חזר לעבוד.
- כפתור שמור PDF עובד שוב.
- יצירת תיקיות אוטומטית: עיר / לקוח / תאריך.
- העלאת PDF לתיקיית התאריך.
- אם כבר קיים PDF באותו שם, הוא מתעדכן.
- אם העלאה נכשלת, מוצעת שמירה בטלפון.

חשוב ב-Google Cloud:
יש להוסיף ב-Data Access את ההרשאה:
https://www.googleapis.com/auth/drive
